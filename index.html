🛠

Bring your own tools

Yoker is a Python-first framework. Every Python function is a Tool. Builtin: File access, git, web search, and more. All configurable, all guarded.

🧠

Any LLM you want

We like Ollama a lot, but also support OpenAI, Anthropic, Gemini, and 100+ more. Switch providers without changing your code.

🛡

Safe by design

No Bash() tool, by design. Static permissions, trust gates and protected files. You decide what an agent can touch. All improving autonomy.

📦

Embed anywhere

Use it as a library in your app, as a CLI, chat with your favorite model or run agentic packages directly from GitHub. Your choice.
